GateKeep: tool-call checkpoint demo

Runs entirely in your browser (static page, no server, no login, no model call). Fixed rules R0 to R5 check each tool call before it would run. This page is a JavaScript port of the Python domain; all 146 benchmark cases give identical verdicts in both (tests/demo).

Limits: tool risk classes are inferred from the tool name and a name that cannot be placed is denied (production should register tools explicitly); money limit 1000, working folder /workspace. CONFIRM never proves a bill is genuine, it only puts the destination and amount in front of the user. GateKeep assumes the agent runtime passes the true user request, allowed tools and untrusted text. It does not catch body tampering sent to an allowed recipient or in-limit amount tampering, and a benign task that takes its recipient or amount from a document can be blocked (false positive). Simulated tools only; no real mail or payment is sent. Rules and results: SPEC.md, results/compare.md.
